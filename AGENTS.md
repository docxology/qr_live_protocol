# AGENTS.md — `qr_live_protocol/`

QRLP v1.6.0: live, verifiable QR codes for stream overlays (timestamps,
blockchain hashes, issuer identity, optional signatures). Python 3.9+,
pip-distributed, CC BY-NC-SA 4.0.

## Layout

- `src/` — implementation (`core.py` QRLiveProtocol coordinator,
  `crypto/`, `time_provider/`, `web_server/`, `qr_generator.py`,
  `blockchain_verifier.py`, `identity_manager.py`, `trust.py`, ...); has
  module README + AGENTS
- `tests/` — pytest suite (see `tests/README.md`)
- `docs/` — 15 topic files + `manuscript/`
- `examples/` — five demo scripts
- `templates/` — dashboard HTML
- `output/` — regenerable demo artifacts
- `main.py`, `run_all.py` — demo / orchestrator entry points
- `pyproject.toml`, `setup.py`, `setup.sh`, `uv.lock` — packaging
- `qr_live_protocol.egg-info/` — pip build metadata (generated; see below)

## Gotchas

- `qr_live_protocol.egg-info/` is generated by pip installs — never hand-edit.
- `run_all.py` is large (38k); prefer `main.py`/`qrlp` CLI entry points.
- Local-only under `projects/ongoing/` — never commit.
- Verify: `python -m pytest tests/ --no-cov -q | tail -1` (README badge says 752 passing / 89% coverage; re-run for current truth — cold collection alone exceeded 280s on the external drive).
