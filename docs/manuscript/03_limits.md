# Interpretation {#sec:limits}

A trusted signature establishes which bytes the registered key signed.
Freshness is evaluated under the verifier's clock and policy. The image
is a visual representation of the payload. This walkthrough checks the
JSON directly and makes no claim about camera decoding or stream-wide
authenticity.

The result applies to the demonstration's payload and trust record. A
downstream use should establish its own issuer trust and event or content
binding before interpreting the result as evidence about a release.
