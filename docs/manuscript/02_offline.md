# Offline walkthrough {#sec:offline}

The local walkthrough creates an ECDSA-signed payload for a fictional
issuer. It disables external time, chain, and timestamping providers. A
separate process verifies the signed JSON with the exported public trust
record and its own key directory. The strict verifier returns success when
the fixture's signature and time checks pass, reporting public-signature trust.

![QR image created by the local walkthrough. The companion signed JSON supplies the input to the strict verification command.](../../output/figures/offline-example.png){#fig:offline-example width=60%}

Figure [@fig:offline-example] is generated by that local walkthrough.
A new run uses a fresh key and timestamp, so its PNG can differ. The
walkthrough verifies the JSON before copying the image into the render output.
