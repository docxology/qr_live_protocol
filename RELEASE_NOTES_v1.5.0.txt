Summary
--------------------------------------------------------------------------------

v1.5.0 is a minor feature release that adds OpenTimestamps (OTS) integration
for QR timestamp attestation. This is an additive, opt-in feature: it layers on
top of the existing NTP + blockchain-hash + signature model and is disabled by
default, so existing behaviour is unchanged.

What OTS does for this project:
  - Commits QR payloads to a public blockchain (Bitcoin) via OpenTimestamps,
    producing a `.ots` proof file.
  - Anyone can verify the proof independently — proving "this QR data existed
    at this time" without trusting any single provider.
  - New CLI commands: `qrlp stamp` (create a proof) and `qrlp verify-ots`
    (verify a proof against the Bitcoin blockchain).
  - Optional automatic periodic stamping during live generation via the
    `ots_*` fields in `TimeSettings`.

--------------------------------------------------------------------------------
Installation
--------------------------------------------------------------------------------

    pip install qr-live-protocol

--------------------------------------------------------------------------------
Usage
--------------------------------------------------------------------------------

    # Stamp a QR JSON payload with OpenTimestamps (writes a .ots proof)
    qrlp stamp qr_data.json --proof-dir output/timestamps/

    # Verify a QR payload against an OpenTimestamps proof
    qrlp verify-ots qr_data.json output/timestamps/<digest>.ots

    # Enable automatic periodic stamping during live generation:
    #   set ots_enabled=true (and ots_server / ots_min_interval / ots_proof_dir)
    #   in the time_settings block of your config file.
